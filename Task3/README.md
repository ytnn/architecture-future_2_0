## Обоснование этапов роадмапа

| Этап                                       | Что делаем                                                   | Зачем бизнесу                                                   | Как влияет                                              |
| ------------------------------------------ | ------------------------------------------------------------ | --------------------------------------------------------------- | ------------------------------------------------------- |
| **Внедрение API Gateway**                  | Единая точка входа, маршрутизация, отключение жёстких связей | Ускоряет подключение новых сервисов (финтех, партнёры)          | Сокращение time-to-market, меньше интеграционных костов |
| **Введение Kafka / Event Bus**             | Потоковые события из клиники и финтеха                       | Устраняет задержки данных, позволяет строить realtime-аналитику | Быстрее отчёты, улучшение качества мед. сервисов        |
| **Data Lakehouse (MVP)**                   | Хранение сырых и очищенных данных, загрузки CDC              | Снижает зависимость от Legacy DWH                               | Быстрее отчётность и новые витрины под продукты         |
| **Semantic Layer / dbt**                   | Единая логика метрик и витрин                                | Устраняет конфликты определений показателей                     | Единые KPI, меньше ошибок в отчётах                     |
| **Data Portal + BI**                       | Self-service доступ к витринам, отчёты                       | Разгружает IT, ускоряет работу аналитики                        | Повышение скорости принятия решений                     |
| **IAM / SSO**                              | Сквозная авторизация, RLS/CLS                                | Требования регуляторов и безопасность                           | Контроль доступа, снижение рисков утечек                |
| **AI Services интеграции**                 | Доступ ИИ к обезличенным данным из Lakehouse                 | Расширение продуктовых возможностей                             | Улучшение диагностики и сервисов клиники                |
| **Миграция данных из Legacy DWH**          | Постепенное копирование историй                              | Минимизирует риски поломок                                      | Плавный переход, устранение bottleneck                  |
| **Onboarding партнёров через API Gateway** | Финтех, фарма, оборудование                                  | Расширение экосистемы                                           | Рост бизнеса за счёт внешних сервисов                   |
