Проект использует Terraform для автоматического развёртывания базовой инфраструктуры в Yandex Cloud.


## **Выбор ресурсов**

- VM (yandex_compute_instance) — требуется для развёртывания тестового окружения.

- Disk (yandex_compute_disk) — отдельный ресурс, позволяющий гибко менять размер и характеристики диска.

- Network (default VPC + default subnet) — используется существующая сеть YC, так как задание не требует создания собственной.

## **Настройки**

- 2 vCPU, 2 GB RAM — минимальный рабочий размер для тестирования.

- NAT = true — нужен доступ в интернет для обновлений.

- SSH ключ — обеспечивает безопасный доступ по SSH.

## **Обоснование использования Terraform**

- Декларативный подход позволяет описывать состояние инфраструктуры как код.

- Структура IaC делает развёртывание воспроизводимым и одинаковым в любых окружениях.

- Любые изменения контролируются через Terraform plan.

- Можно легко масштабировать инфраструктуру, добавляя новые VM, базы, сети.

## Как подход Infrastructure as Code (IaC) способствует воспроизводимости и масштабируемости инфраструктуры

Декларативный подход позволяет описывать инфраструктуру как конечное состояние, а Terraform автоматически приводит облако к этому состоянию, что исключает ручные ошибки и расхождение окружений. IaC обеспечивает воспроизводимость — любую среду можно развернуть заново по тем же конфигурациям, а изменения контролируются через terraform plan и версионирование. Такой подход упрощает масштабирование: добавление новых VM, сетей или сервисов сводится к изменению кода, а не ручным операциям, что делает инфраструктуру предсказуемой, управляемой и удобной для автоматизации.
